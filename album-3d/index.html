CritérioWebGL · Three.jsCSS 3D puro
Peso adicionado 633 KB min / 154 KB gzip (three.min.js r152) + ~7 KB de cena ≈ 6 KB de HTML + CSS + JS, sem bibliotecas
Realismo Luz direcional com sombra, material com rugosidade, textura de tecido e foil com relevo via canvas Iluminação simulada com gradientes estáticos por face; sem sombra dinâmica nem material
Personalização Textura da capa redesenhada em canvas a cada mudança (cor, nome, foil) — extensível a fotos do cliente nas páginas Custom properties CSS + background-clip: text; simples, mas limitado a efeitos 2D na capa
Mobile WebGL é universal, mas exige teto de DPR e atenção a memória no Safari iOS Transforms com aceleração nativa; excelente em aparelhos de entrada
Caminho no tema Shopify Import dinâmico só na PDP variante B, disparado na primeira interação (fora do LCP) Inline na própria section Liquid; custo praticamente zero no carregamento
Evolução (folhear páginas, fotos reais) Natural: geometria de página com curvatura, texturas por foto Possível, mas o custo de fidelidade cresce rápido além da capa
